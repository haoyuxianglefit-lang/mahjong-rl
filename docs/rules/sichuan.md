# 四川麻将（血战到底）规则要点 —— 规则迁移蓝图（待细化）

> 落地引擎时逐条核对 obs 面 / 动作空间 / 奖励函数的影响。

## 与规则引擎直接相关的差异
| 项 | 日麻 | 川麻（血战到底） | 对 AI 工程的影响 |
|---|---|---|---|
| 牌张 | 136（含字牌） | 108（无字牌无花） | 字牌编码行置零；tile_count 108 |
| 吃 | 有 | 无 | 动作空间去掉 chi |
| 立直 | 有 | 无 | 去掉立直动作与相关 obs 面 |
| 宝牌 | 指示牌+里宝+红宝 | 无（部分玩法有） | 去掉 dora 特征面 |
| 定缺 | 无 | 开局必须选一门弃绝 | **新增独立决策点/head** |
| 换三张 | 无 | 常见变体：起手换 3 张同花色 | 开局阶段逻辑；破坏花色对称性增强 |
| 多胡 | 一家和牌即终局 | 一家和牌其余继续，直至剩一家或摸完 | multi_win 结算；已胡家数进 obs |
| 杠 | 岭上补牌+宝牌 | 刮风下雨：杠分即时结算，杠后点炮要转移杠分 | 奖励 shaping 即时化 |
| 查叫 | 无 | 流局查叫，未听牌向听牌家付费 | 终局结算规则 |
| 过手规则 | 振听 | 放过某张后同巡不能再胡同种 | 类似实现 |

## 番型/打分
- 基础番型：平胡、清一色、碰碰胡、七对、金钩钓、杠上花等；封顶常见 8 番
- 自摸加倍 / 点炮者独付（变体多，需选定一种固定进 RuleSpec.extra）

## 数据来源（现实约束）
- 川麻**没有**天凤级公开牌谱库；候选：官方回放导出、约局录谱、商用 App 回放（注意合规）
- 零数据替代：MCTS/专家老师蒸馏 + 纯自对弈 RL（见 docs/adr/0001）
