# 麻将 AI 训练方法对比：LuckyJ vs Suphx vs NAGA vs Mortal

> 整理时间：2026-09-07
> 说明：LuckyJ 与 NAGA 未公开完整技术细节，本表基于官方博客、已发表论文（Suphx: arXiv:2003.13590）及公开报道整理，未公开处以"未披露"标注。

## 一、总览对比表

| 维度 | LuckyJ（绝艺） | Suphx（超级凤凰） | NAGA |
|---|---|---|---|
| 开发者 | 腾讯 AI Lab | 微软亚洲研究院 | Dwango Media Village（日本） | Equim-chan（个人开源项目） |
| 发布 / 登顶时间 | 2023 年 5 月达十段 | 2019 年上线，首个达十段的麻将 AI | 2019 年起在天凤运行 | 2022 年 4 月开源 |
| 对战平台 | 天凤（日麻）+ 国标麻将 | 天凤（日麻） | 天凤（日麻） | 本地/自建服务（mjai 协议），未打天凤段位战 |
| 是否使用人类数据 | 否，完全从零自我博弈 | 是，先用天凤高手牌谱做监督学习 | 是，基于人类牌谱的深度学习 | 否，纯自我博弈深度强化学习 |

## 二、各 AI 的训练流程详解

### 1. Suphx（微软，2020 年论文公开，细节最完整）

四阶段流水线：

1. **监督学习（SL）预热**：用天凤平台顶级人类玩家的牌谱，训练 5 个模型——出牌、立直、吃、碰、杠模型，让 AI 先达到"高手模仿"水平。
2. **深度强化学习（DRL）**：以自我博弈的 PPO 风格策略梯度继续训练，并引入一系列针对麻将的技巧：
   - **全局奖励预测**：预测整局最终得分，把"一局的输赢"分摊为每步决策的信用分配信号，缓解奖励稀疏；
   - **先知教练（Oracle Coach / 变分潜在先知）**：训练时引入"能看到所有隐藏信息"的先知特征加速收敛，再通过变分方法逐步撤掉先知信息，让模型只依赖可观察信息也能保持水平；
   - **参数化蒙特卡洛策略自适应（pMCPA）**：对局在线阶段，根据对手的实际行为做 rollout 模拟，实时微调离线策略的输出。
3. 大量分布式自我博弈积累对局经验。

特点：**工程技巧密集、复现门槛高**（需要天凤牌谱数据 + 大规模算力），学术圈多次反馈难以完整复现。

### 2. LuckyJ（腾讯，2023 年，框架级公开）

两大核心组件：

1. **离线训练——ACH（Actor-Critic-Hedge）策略优化算法**：
   - 动机：纯强化学习在非完美信息博弈中无收敛保证，策略易"偏科"；CFR 类遗憾最小化有理论保证但算不动麻将的规模；
   - 做法：以 Actor-Critic 保证深度网络下的可扩展性，融合 Hedge（遗憾最小化）更新，部分继承 CFR 的理论性质；
   - **零人类数据**：纯自我博弈从零开始，最终收敛到"攻守兼备"的混合策略；
   - 配套训练加速技术（团队相关论文）：**奖励方差缩减（RVR）**——用"相对价值网络"借全局信息引导收敛，用"期望奖励网络"平滑麻将高度随机、稀疏的奖励。
2. **在线推理——乐观价值估计的非完美信息搜索**：
   - 传统非完美信息搜索复杂度是隐藏信息量的平方，麻将有一百多张隐藏牌，直接搜索不可行；
   - LuckyJ 基于乐观价值估计设计高效搜索，在实战中根据当前局面**实时调整离线策略**，相当于给固定策略加"临场精算"。

特点：**不使用任何人类数据**是它与 Suphx 最大的路线差异；理论动机（博弈论收敛性）更强，但完整实现细节未披露，复现困难。

### 3. NAGA（Dwango，细节最少）

- 以**深度卷积神经网络 + 人类牌谱监督学习**为主体，属于"学习型 AI"；
- 不使用蒙特卡洛模拟等在线搜索，出牌接近实时；
- 官方曾用脱出水准（天凤标准段位期望）评估，自称强于当时所有公开麻将 AI；
- 天凤长期对局成绩稳定在十段级别。

特点：路线最"轻"——无 RL 自我博弈、无在线搜索，靠高质量监督模型即可达到十段，但天花板也最受限于人类数据。

### 4. Mortal（Equim-chan，2022 年开源，个人项目）

与前三者（大厂/机构出品）完全不同，Mortal 是**单人开发的开源项目**，也是目前唯一代码完整公开的高水平日麻 AI：

1. **训练方式：纯自我博弈深度强化学习，零人类数据**：
   - 价值学习路线（DQN 风格）：网络输出各动作的 Q 值，用自我对局产生的经验回放池训练；仓库中还包含"基线（baseline）"网络做方差缩减/评估；
   - 训练流水线：`train.py` 训练循环 + 1v3 对战评估（`one_vs_three.py`，新模型挑战冠军模型），定期淘汰弱版本，实现类似"联赛式"的迭代进化；
   - 附带少量工程组件：如基于规则的"胡牌守护"（rule-based agari guard），防止明显错误的过水决策。
2. **性能工程是核心竞争力**：
   - 模拟器用 **Rust** 编写（libriichi），带 Python 接口，Rust 模拟 + Python 推理可达**每小时约 4 万个半庄**的自我对局吞吐——个人算力下能训出强 AI 的关键；
   - 支持 AMP 混合精度、PyTorch compile 等加速选项。
3. **发布策略：开源代码、不开放权重**：
   - 2022-04 开源全部源代码（GitHub: Equim-chan/Mortal），但因担心被用于雀魂/天凤外挂，2022-08 作者明确决定**不发布训练好的模型参数**，改为提供在线服务（mjai.ekyu.moe，牌谱检讨/复盘）；
   - 兼容 mjai 协议，是目前中文社区最主流的**牌谱复盘工具后端**（mjai-reviewer）。
4. **水平定位**：作者自测强于 akochan 等所有可得 baseline，"约相当于早期 Suphx"；因未打天凤段位战，无官方段位，社区普遍认为在十段门槛附近。

特点：**小团队/个人可复现性最强**——代码、训练配置、文档全部公开，缺的是算力和训练好的权重；路线与 LuckyJ 同属"无人类数据自我博弈"，但没有博弈论算法层面的创新，靠的是高质量工程实现。

## 三、关键差异解读

1. **数据来源的分歧**
   - Suphx / NAGA：人类牌谱启动（模仿学习）；
   - LuckyJ / Mortal：完全自我博弈（更接近 AlphaZero 路线）。
   这意味着 LuckyJ、Mortal 的策略不受人类定式束缚，能发现人类没有的最优混合策略（例如更精确的攻防平衡点）。

2. **理论保证 vs 工程堆料**
   - Suphx 靠先知教练、全局奖励预测等工程技巧解决信用分配问题；
   - LuckyJ 从算法层面（ACH）引入博弈论收敛性质，再配 RVR 解决奖励方差。

3. **在线搜索的必要性**
   - 三者中 NAGA 无搜索仍达十段，说明强离线策略本身已足够强；
   - LuckyJ 和 Suphx 都用在线机制（搜索 / pMCPA）在离线策略之上再做增益，这也是它们稳定段位更高的原因之一。

4. **成绩与效率**
   - 从零到十段所需局数：LuckyJ 1321 局 ≪ Suphx 5373 局；
   - 统计显著性：LuckyJ vs Suphx p = 0.02883；LuckyJ vs NAGA p = 3e-05（bootstrap 分布检验）。

## 四、对本项目的启示（如需自研麻将 AI）

| 自研目标 | 建议路线 |
|---|---|
| 算力有限、快速出成果 | NAGA 式：监督学习 + 牌谱数据（需解决数据来源） |
| 无牌谱数据、有中等算力 | LuckyJ 式：自我博弈 RL，配合奖励方差缩减；可先用课程学习降低训练难度 |
| **个人/小团队、要可复现** | **Mortal 式：Rust 高速模拟器 + DQN 风格自我博弈 + 1v3 联赛评估；可直接 fork 其代码起步** |
| 追求理论收敛保证 | 在 Actor-Critic 上叠加 CFR/Hedge 类更新（ACH 思路） |
| 已有离线模型想再提升 | 加在线机制：pMCPA 式 rollout 或乐观价值搜索 |
