## 绑定过程存档（已完成，仅供排错参考）

1. Cloudflare 添加站点 mahjongai.com.cn（Free 套餐）→ 得到两个 NS。
2. 阿里云域名控制台 → DNS修改 → 自定义 DNS 服务器 → 填入两个 NS → 手机验证码确认。
3. 本机执行：
   ```bat
   tunnel\cloudflared.exe tunnel login        :: 浏览器授权，生成 cert.pem
   tunnel\cloudflared.exe tunnel create mahjongai
   tunnel\cloudflared.exe tunnel route dns mahjongai mahjongai.com.cn
   tunnel\cloudflared.exe tunnel --config tunnel\config.yml run
   ```
   - 说明：域名解析到 Cloudflare/境外，**不需要 ICP 备案**。
